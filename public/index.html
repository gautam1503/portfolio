    Engineering decisions

    • No framework, no bundler. The page ships as plain HTML/CSS/JS: nothing to compile, instant first paint, trivial to audit.
    • Content as data. Every word lives in one profile.js; the UI renders from it, like a CMS without the CMS.
    • Cache in layers. Server memory → CDN → browser session, all 2 min, so GitHub's 60 req/hr limit is never hit while data stays fresh.
    • Defence in depth. CSP headers, input validation, honeypot, per-IP rate limiting, HTML-escaped emails.
    • Graceful degradation. No backend? The form falls back to mailto:. GitHub down? Cached data, then a link.
    • Accessible motion. Every animation honours prefers-reduced-motion; sound is opt-out and remembered.
